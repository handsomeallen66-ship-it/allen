# 订货会系统需求方案（iPad / App / 微信小程序）

## 1. 项目目标
打造一套支持**实时订货**的订货会系统，面向品牌方、代理商、门店客户。系统需同时支持：
- iPad/平板端（展会现场下单）
- 原生 App（可选）
- 微信小程序（二期支持，便于推广）

核心目标：客户下单后，库存、排行榜、区域数据可实时更新，帮助运营团队快速掌握销售动态并控制超卖风险。

---

## 2. 角色与使用场景

### 2.1 角色
- **客户/订货商**：浏览商品、选择 SKU、下单、查看订单状态
- **销售/业务员**：协助客户下单、查看客户排行与区域订货情况
- **运营管理人员**：管理商品、库存、订单、活动配置
- **管理员**：账号权限配置、系统参数、数据导出、审计日志

### 2.2 场景
1. 展会现场客户用 iPad/平板下单，后台实时扣减可售库存。
2. 总部大屏实时展示“订货排行 Top N”“区域排行”。
3. 客户注册后补全企业资料，审核通过后才能参与订货会。
4. 同步支持 App 与小程序，保证跨端账号统一。

---

## 3. 核心功能清单

## 3.1 实时订货与库存联动（必须）
- 商品支持多 SKU（颜色、尺码、款式、批次）。
- 下单时实时校验库存：
  - 锁库存时机采用“提交订单锁库存”（固定策略）
  - 并发保护防止超卖（乐观锁/库存预占机制）
- 订单状态流转：待提交、已提交、待审核、已确认、已取消。
- 支持草稿单（客户可反复编辑）。
- 支持起订量（MOQ）与整包规则（如每箱 12 件）。

## 3.2 订货数据看板（必须）
- **客户订货排行**：Top 1~Top N（按件数排行）
- **区域订货排行**：省、市、大区维度聚合
- 商品热销榜：按款号/SKU 排行
- 时间维度：实时、今日、活动周期
- 大屏模式：自动轮播、每 5~10 秒刷新

## 3.3 用户注册与资料管理（必须）
- 注册方式：手机号验证码 / 微信授权登录
- 企业信息表单：公司名称、联系人、区域、渠道类型、税号等
- 资质上传：营业执照、授权书等
- 审核流程：单步审核（待审核、通过、驳回，含驳回原因）

## 3.4 订单与报表（必须）
- 订单查询：按客户、区域、时间、状态筛选
- 导出报表：订单明细、SKU 汇总、客户汇总、区域汇总
- 订单版本追踪：记录每次修改前后差异
- 支持打印/导出 PDF（用于现场签字确认）

## 3.5 多端支持（必须）
- 小程序端：客户自助订货、查看订单、消息通知（二期）
- iPad App：大屏化购物界面、快速选款（首发端）
- App 端（可选）：适用于经常复购客户，支持推送
- 管理后台（Web）：商品、库存、订单、用户、权限、报表管理

---

## 4. 推荐技术架构

## 4.1 前端
- 小程序：微信原生小程序 / uni-app
- iPad 与平板：PWA 或 uni-app（可快速跨平台）
- 管理后台：Vue/React + 组件库

## 4.2 后端
- API 服务：Java/Spring Boot 或 Node.js/NestJS
- 数据库：MySQL/PostgreSQL
- 缓存与实时：Redis（库存预占、排行榜实时统计）
- 消息队列：Kafka/RabbitMQ（订单事件、异步统计）
- 实时通道：WebSocket（看板实时刷新）

## 4.3 部署与运维
- 云部署：阿里云/腾讯云
- 对象存储：OSS/COS（图片、资质文件）
- 监控：Prometheus + Grafana
- 日志：ELK 或 Loki

---

## 5. 数据模型（最小集合）
- 用户表（账号、角色、状态）
- 客户企业表（区域、渠道、资质）
- 商品 SPU 表
- 商品 SKU 表（颜色、尺码、库存、可售状态）
- 库存流水表（冻结、扣减、回补）
- 订单主表
- 订单明细表
- 排行统计表（可实时计算+定时落库）

---

## 6. 关键业务规则
1. **防超卖**：库存扣减需原子化；下单并发需限流与重试。
2. **价格策略**：可按客户等级、区域、活动价差异定价。
3. **权限隔离**：客户只看自己的订单；区域经理看所属区域数据。
4. **ERP 对接**：打通商品、客户、库存、订单主数据与单据回传。
5. **活动时段控制**：未到开始时间不可下单，结束后只读。
6. **审计合规**：所有订单关键动作（创建、修改、审核、取消）留痕。

---

## 7. MVP（第一期）建议范围
优先上线以下模块，保证 6~10 周可交付：
- 客户注册 + 审核
- 商品/SKU 展示
- 下单 + 库存实时校验
- 基础订单管理
- 客户/区域排行看板
- 报表导出（Excel）
- ERP 对接（商品/库存/订单）

二期再扩展：
- 智能推荐补货
- 多仓库存分配
- 财务对账与回款
- CRM/ERP 对接
